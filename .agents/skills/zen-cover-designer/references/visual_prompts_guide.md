# 心茶記 (Mind Tea Journal) 視覺美學與提示詞工程指南

本專案所有封面與宣傳圖均需維持「心茶記」一貫之高質感東方茶禪意境。

---

## 🎨 核心視覺基調 (Core Visual Tone)

1. **空間氛圍**：安靜、溫潤、留白、深層覺察、沉澱心神、東方極簡生活美學。
2. **器物焦點**：
   - 粗陶或汝窯手作茶杯/茶壺（帶溫熱琥珀色茶湯與細膩氤氳茶氣）。
   - 自然原木茶几（如溫暖橡木、胡桃木、雪松木紋）。
   - 傳統或自然材質配件（竹茶筅、陶承、亞麻杯墊、暗色岩石茶盤、和紙手帳等）。
3. **光影與視角**：
   - 晨曦柔光或黃昏側逆光、透過格柵或紗簾的斑駁光影。
   - 大光圈微距/淺景深（Shallow depth of field, f/1.8 - f/2.8），主體清晰、背景柔焦虛化。
4. **絕對負面提示詞 (Negative Constraints - 鐵律)**：
   - `ABSOLUTELY NO TEXT, NO LETTERS, NO WORDS, NO NUMBERS, NO WATERMARKS, NO TYPOGRAPHY, NO LOGO, NO SIGNATURE.`
   - 嚴格禁止任何文字、英文字母、數字、浮水印或簽名。

| 文章主題 | 隱喻道具 / 意象 | 構圖說明 |
| :--- | :--- | :--- |
| **情緒解離 / 接納** | 窗外陰雨暴雨，室內溫暖茶桌與閉合信封 | 外界狂風暴雨，但室內安全寧靜，象徵不將外界風雨當成自我判決。 |
| **認知差異 / 語境** | 攤開手繪等高線地圖的復古手帳與木鋼筆 | 象徵「地圖不是疆域」，文字概念與真實世界的落差。 |
| **物理媒介 / 數位降噪** | 輕巧闔上或微閉的筆記型電腦 + 溫暖冒氣陶杯 | 焦點從冰冷數位螢幕轉向當下的真實存在與體溫。 |
| **身心耗竭 / 能量滋養** | 榻榻米上的茶燭溫茶爐，柔和燭光與茶壺 | 象徵神經系統的深度復原與身心滋養，安歇才能好好對話。 |
| **情緒色彩 / 語氣風暴** | 暗色板岩茶盤上的無波水碗，平靜倒映一葉綠茶 | 象徵風暴止息後的極致澄澈與靜止。 |
| **信念冰山 / 價值觀** | 老松微型盆景 + 晨光穿透的老式光學稜鏡 | 扎根的盆景代表深層信念；稜鏡折射七彩光譜代表看見多元視角。 |
| **打破標籤 / 清新相遇** | 玻璃蓋碗中隨熱水舒展開來的翠綠茶葉 | 剔透玻璃與初展嫩葉，代表摘除成見眼鏡後的透明視野。 |

| **對話之橋 / 彼此共鳴** | 兩人對坐茶席，一席深色織錦茶席布連接兩只茶杯 | 象徵生命相遇（I-Thou），在喧囂中搭建清澈對話之橋。 |
